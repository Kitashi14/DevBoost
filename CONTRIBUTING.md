# Contributing to DevBoost

Thank you for your interest in contributing to DevBoost! We appreciate any improvements or new features.

## How to Contribute

1. **Fork and Clone**
   ```bash
   git clone https://github.com/YOUR_USERNAME/DevBoost.git
   cd DevBoost
   npm install
   ```

2. **Create a Branch**
   ```bash
   git checkout -b feature/your-feature-name
   ```

3. **Make Changes**
   - Follow TypeScript best practices
   - Test in Extension Development Host (Press F5)
   - Run `npm run lint` before committing

4. **Commit and Push**
   ```bash
   git commit -m "feat: describe your changes"
   git push origin feature/your-feature-name
   ```

5. **Open a Pull Request**
   - Provide clear description of changes
   - Reference related issues

## Guidelines

- Follow TypeScript best practices and conventions
- Test cross-platform compatibility (Windows/macOS/Linux)
- Add JSDoc comments for complex functions (preferred)
- Use descriptive commit messages (conventional commits format preferred)

## Reporting Issues

[Open an issue](https://github.com/Kitashi14/DevBoost/issues) with:

- **Bug**: Description, steps to reproduce, expected vs actual behavior, VS Code/OS version
- **Feature Request**: Description, use case, motivation
